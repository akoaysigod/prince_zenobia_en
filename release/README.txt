Densetsu no Ogre Battle Gaiden: Zenobia no Ouji
English translation patch for the Neo Geo Pocket Color
=====================================================

This is a fan translation of "Densetsu no Ogre Battle Gaiden: Zenobia no
Ouji" (SNK, 2000) into English. It comes as a patch only: no game data is
included, and you need your own copy of the original Japanese ROM.


WHAT'S TRANSLATED
-----------------
- All story dialogue, and the tarot reading at the start of the game.
- Menus, menu captions and help text, the status, battle and
  settlement screens, and system and save messages.
- Names of characters, units, classes, items, tarot cards, attacks,
  spells and towns.
- Name entry: a new a-z page replaces the hiragana page.

Not translated:
- The title logo, kept as the original artwork.
- The link-cable menus for two-player play.

Name fields are 8 characters wide, so some long names are shortened
(for example "B.Knight" for Black Knight and "H.Priest" for High
Priestess).


APPLYING THE PATCH
------------------
1. Start from the original, unmodified ROM:
     File:   Densetsu no Ogre Battle Gaiden - Zenobia no Ouji.ngc
     Size:   2,097,152 bytes (2 MB)
     CRC32:  EEEEFD6A
     MD5:    26d0557d8a465aa8f430d5e4d94c679a
     SHA-1:  5ac794c0f125bfb97efe9cd06c2aca3afdf549ea
   The patch won't work on a ROM that has been changed in any way.
2. Apply ogre_battle_en.ips with any IPS patcher, for example:
     Floating IPS (Flips):  https://www.romhacking.net/utilities/1040/
     ROM Patcher JS:        https://www.marcrobledo.com/RomPatcher.js/
3. Keep a copy of the original ROM. Patch a copy, not the original.

Old save states won't carry over to the patched game, because they hold
the previous game's memory. In-game saves work normally.
